# PiDeck v0.2.0 — 首个开源 Beta

这是 PiDeck 的第一个公开开源版本。PiDeck 是 Pi 的非官方桌面界面：Agent、模型、工具、Session、Extension、Package、权限和凭据仍由 Pi CLI / SDK 管理，PiDeck 不在外面再造一套实现。

当前适配基线为 Pi CLI / SDK `0.85.1`、`@gotgenes/pi-permission-system` `31.1.1` 和 Electron `43.4.1`。本次发布已使用 `Qwen Token Plan CN / DeepSeek V4 Pro 0813` 完成真实模型调用与文件修改验收。

English documentation is available in the [README](https://github.com/vulcanen/PiDeck/blob/v0.2.0/README.en.md) and the complete [Pi CLI → PiDeck feature matrix](https://github.com/vulcanen/PiDeck/blob/v0.2.0/docs/pi-cli-feature-matrix.en.md).

## 完整支持功能

### 项目与 Session

- 发现和添加本地项目；多个项目可同时展开，按更新时间显示各自的 Session。
- 新建、打开、切换、恢复、重命名和删除 Session；从侧栏移除项目不会删除项目文件或 Pi Session。
- 项目级 Pi 资源授权，支持项目决定、父目录继承和全局默认策略，控制项目设置、Extension、Skill、Prompt、Theme、Package 和系统提示的加载。
- 从 Pi 的完整 Session 分支恢复对话；上下文压缩后仍保留桌面时间线中的历史消息。
- 自动生成会话短标题并持久化；模型生成失败时保留稳定的本地标题。
- 保存并恢复每轮执行耗时；Steering 继续归入当前执行组，Follow-up 创建新的执行组。
- 当前 Session 内搜索，长会话按 200 条逐步展开；项目切换后保留各会话的滚动位置。
- `/fork`、`/clone` 和 `/tree` 共用 Session Tree 浏览器，支持搜索、键盘导航、活动路径、分叉点、影响预览和可取消的离开分支摘要。
- 通过原生文件选择器导入 JSONL Session，并可导出 HTML 或 JSONL。
- `/share` 复用本机已登录的 `gh` CLI 创建分享内容。

### Provider、模型与 Pi 设置

- 浏览、搜索并按认证状态筛选 Pi Provider。
- 使用 API Key 或 OAuth 登录和移除认证；凭据继续保存在 Pi 的本机配置中，不进入 Renderer。
- 使用 Pi 运行时提供的模型目录选择模型，支持 Extension 动态注册的 Provider 和 Model。
- 按模型能力显示并持久化 Thinking Level；支持全局默认值和单模型覆盖。
- 配置模型范围：按 Provider/Model 搜索、整组选择或清空、调整顺序，并使用 Pi 原生模型轮换。
- 编辑 Pi 高级设置，包括 Agent/Provider 重试、压缩与分支摘要限制、`branchSummary.skipPrompt`、Thinking、图片处理、默认工具、项目默认授权、Shell/npm/Session 目录、Skill 命令、警告和遥测开关。
- 支持 `HTTP_PROXY`、`HTTPS_PROXY`、`NO_PROXY`、Pi `httpProxy` 和系统代理，以及 HTTP 空闲超时、WebSocket 连接超时与 `websocket-cached` 传输。
- 设置通过 Pi 的锁定存储写入，保留未知和嵌套字段；项目设置继续覆盖用户设置。

### 对话与输入

- 实时显示 Agent 回复、Thinking、工具调用、执行结果、成功或失败状态和耗时。
- 运行时按 Pi 事件顺序交错展示 Thinking 与工具 Activity；完成后收进可展开的执行摘要。
- 渲染 Markdown、语法高亮代码、Mermaid 图和 KaTeX 数学公式。
- 支持图片粘贴和拖放、`@file` 工作区文件提示、Prompt/Skill/命令补全及用户输入历史。
- Steering / Follow-up 队列支持模式切换、清空、提升、编辑和删除；队列条目保留顺序、稳定标识和图片缩略图。
- 自动压缩期间继续安全接收队列输入；手动压缩可取消，取消或失败后不会丢失暂存消息。
- 支持 Pi `keybindings.json` 对应的搜索、模型、Thinking 和外部编辑器动作。
- 可自动发现或手动选择外部编辑器，支持 macOS、Windows 以及包含空格的 Unix 应用路径。

### 工具、Shell 与权限

- 运行 Pi 内置工具、Extension 工具和项目自定义工具；默认工具完全由 Pi `settings.json` 决定。
- 在桌面审批卡中处理工具调用。
- 通过 `@gotgenes/pi-permission-system` 使用 `allow`、`ask`、`deny` 和 `yoloMode`，并在 Composer 中切换当前权限。
- 使用 `!command` 和 `!!command` 执行 Pi Shell 命令；支持停止执行，`!!` 不把输出加入模型上下文。
- 展示自动重试和摘要重试的次数、等待时间、阶段、完成状态与最终错误。

### 命令与 CLI 兼容

- Composer 和快捷设置读取 Pi 的真实 slash command catalog，包括内置命令、Prompt、Skill 和 Extension command。
- 已接入 `/settings`、`/reload`、`/import`、`/share`、`/copy`、`/name`、`/session`、`/changelog`、`/hotkeys`、`/trust`、`/resume`、`/quit`、`/scoped-models`、`/compact`、`/export`、`/model`、`/thinking`、`/login`、`/logout`、`/fork`、`/clone` 和 `/tree`。
- `/model provider/model` 保留完整 Provider/Model ID；`/export 路径` 支持空格和覆盖确认。
- `/reload` 重新加载 Pi Settings、Package、Extension、Prompt、Skill、Theme 和模型注册表。
- `npm run cli -- <Pi 参数>` 与 `pideck-cli` 直接委托给 Pi 官方入口，支持 Print、JSON、RPC、stdin JSONL、Session 参数和 `auth print-*`。

### 文件改动审查

- 以每轮 Agent 执行为单位记录 Git 工作树变化，排除运行前已有且本轮未改动的脏文件。
- 按目录和文件浏览改动，支持搜索、筛选、键盘导航、复制路径以及轮次状态、日期和耗时。
- 支持 Unified Diff 和 Codex 风格 Split Diff、换行、仅空白过滤、语法高亮、变更块导航与增量行折叠。
- 支持逐块接受或撤销，以及基于 CodeMirror 的可编辑合并。
- 使用 revision 校验、文件修改锁、原子写入和失败回滚，避免覆盖同时发生的外部修改。
- 识别重命名、删除、权限模式变化、二进制文件、超大文件和截断 Patch；不能安全处理的内容保持只读。
- 按 Session 恢复审查轮次、选中文件、目录状态、面板尺寸、显示选项和滚动位置。

### Pi Package、Extension 与 Theme

- 按用户级或项目级作用域安装、移除、启用、停用和更新 Pi Package。
- 浏览并切换 Package 中的 Extension、Skill、Prompt 和 Theme 资源，支持检查单包或全部更新。
- 运行 Extension command 和经过 Pi 冲突处理的扩展快捷键，并同步 Composer 编辑文本。
- 映射 Extension UI 的 `select`、`confirm`、`input`、`editor`、`notify`、状态、Working Indicator、文本/组件 Widget、Footer、Header、标题和自定义编辑器。
- 在 PiHost 中渲染 TUI 自定义组件并转发按键，保留 terminal input、autocomplete provider 和 Pi 原生 `/llama` 流程。
- 加载 Pi 内置及资源 Theme；Theme 可按 Session 覆盖并同时作用于工作区和浮层。
- 展示 Extension 加载、命令、快捷键、模型回退、异步错误和 shutdown 请求等诊断信息。

### 桌面体验与运行时

- 中文和英文界面、浅色和深色主题。
- macOS 原生菜单，以及 Windows 的编辑、查看和帮助菜单；窄窗口使用响应式项目抽屉和设置抽屉。
- 快捷设置集中提供 Provider、Pi 设置、Package、模型范围、任务操作和 Pi 命令。
- Sidebar 显示 PiHost Runtime 状态；启动失败会显示脱敏且可操作的错误。
- Renderer 只通过 Preload Bridge 访问 Pi；凭据、Session、模型对象和 Extension 组件实例留在 PiHost。
- PiDeck 不收集使用分析数据；项目列表和界面偏好之外的数据继续由 Pi 管理。
- “关于 PiDeck”显示应用版本和当前 Pi SDK 版本。

## 当前限制

- 暂不提供 Linux 安装包，也没有应用内自动更新。
- 本版本未签名、未公证；系统安全提示属于预期情况。
- PiDeck 没有独立终端面板；Shell 使用 `!command` / `!!command`，Print/JSON/RPC/stdin/Auth Print 使用 CLI 入口。
- 二进制、超大或截断的文件差异不能逐块处理或编辑合并。
- 文件审查不负责 Git staging 或 commit。
- 依赖像素级终端绘制或任意 DOM 的 Extension 仍需在 Pi CLI 中使用。
- 当前只保证与 Pi SDK `0.85.1` 兼容。

完整实现边界与技术映射见 [Pi CLI → PiDeck 功能矩阵](https://github.com/vulcanen/PiDeck/blob/v0.2.0/docs/pi-cli-feature-matrix.zh-CN.md)。
