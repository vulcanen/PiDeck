# Documentation assets

The PNG files in this directory are screenshots captured from PiDeck for this
repository's documentation. The interface-tour screenshots were produced from
a real `Qwen Token Plan CN / DeepSeek V4 Pro 0813` run in an isolated demo
workspace. They contain no API keys, user credentials, private project content,
or private session content.

- `pideck-conversation.png`: completed conversation and change summary
- `pideck-live-activity.png`: live thinking and tool execution
- `pideck-change-review.png`: file and hunk review
- `pideck-session-tree.png`: Pi session-tree navigation
- `pideck-pi-settings.png`: Pi model and behavior settings
- `pideck-provider-settings.png`: provider authentication status
- `pideck-quick-settings.png`: quick settings panel
- `pideck-workspace.png`: empty workspace overview
